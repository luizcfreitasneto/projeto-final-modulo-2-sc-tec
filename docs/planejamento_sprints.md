
# Planejamento em Sprints — Projeto PNCP 2025

## Objetivo
Organizar as atividades de desenvolvimento do projeto de análise de contratações públicas, desde a preparação do ambiente até a entrega final.

Este documento apresenta uma organização retrospectiva das atividades desenvolvidas, sem atribuir datas de execução não registradas.

## Sprint 1 — Preparação e exploração dos dados
- Configuração do ambiente Python e dependências.
- Criação do repositório GitHub.
- Inspeção dos arquivos compras.csv, itens.csv e resultados.csv.
- Identificação de colunas, valores ausentes e duplicidades.

Status: Concluída.

## Sprint 2 — Qualidade e tratamento dos dados
- Auditoria de formatos monetários e datas.
- Validação de relacionamentos entre as tabelas.
- Implementação das rotinas de limpeza.
- Documentação dos problemas encontrados.

Status: Concluída.

## Sprint 3 — Modelagem dimensional
- Definição do modelo Star Schema.
- Construção das dimensões de órgãos, fornecedores, modalidades e localidades.
- Construção da tabela fato de itens contratados.

Status: Concluída.

## Sprint 4 — PostgreSQL e análises SQL
- Criação das estruturas do banco de dados.
- Carregamento das tabelas dimensionais.
- Validação das relações entre fato e dimensões.
- Desenvolvimento das consultas analíticas.

Status: Concluída.

## Sprint 5 — Dashboards Power BI
- Conexão com o PostgreSQL.
- Construção das medidas DAX.
- Desenvolvimento das seis páginas de análise.
- Testes de filtros, navegação e indicadores.

Status: Concluída.

## Sprint 6 — Documentação e entrega
- Elaboração do README.
- Publicação dos scripts e dashboard no GitHub.
- Revisão dos requisitos avaliativos.
- Preparação do vídeo e entrega no AVA.

Status: Em andamento.

## Observações
As Sprints representam agrupamentos lógicos das atividades realizadas. Não foram atribuídas datas ou durações históricas sem evidências.
